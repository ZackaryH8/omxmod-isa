# Reference icons

The three ISA PNGs are extracted from printed page 44 (PDF page 4) of
[TfL New Bus Specification v2.7, ISA extract](https://foi.tfl.gov.uk/FOI-1516-2627/Bus%20Vehicle%20Specification_v2.7_ISA.pdf).
To reproduce the extraction, run `bash tools/extract-icons.sh` from the repository root. Black backgrounds are removed
at runtime using the OMX HUD colour key. The green crop excludes the grey left border.
